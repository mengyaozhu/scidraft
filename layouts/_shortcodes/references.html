{{- /* Reference list for one paper. Usage, with both arguments shown: {{< references bib="bib/paper-a.bib" title="References" >}} bib required. Path of the bibliography under the site's assets/ directory, for example bib/refs.bib or bib/paper-a.bib. There is deliberately no default file: a site that publishes several papers keeps one bibliography per paper, and a silent default would hide a note that forgot to name its own. title optional. Text of the heading rendered above the list. Omit it to place the list under a heading the note writes itself. A note may carry several of these, each naming its own file, and each list is numbered and filled independently (the loader in extend_head.html scopes citations to the text that precedes each list). The whole element is emitted hidden and is revealed by the loader once the entries are in place, so a heading never appears above an empty list. A missing bib argument or a file that is not under assets/ fails the build, which is the only way this stays honest: the alternative is a page that renders reference markers and no bibliography, with no hint why. */ -}} {{- $source := .Get "bib" -}} {{- $title := .Get "title" -}} {{- if not $source -}} {{- errorf "references shortcode in %s: a bib argument is required, for example references bib=\"bib/refs.bib\"" .Page.File.Path -}} {{- else -}} {{- $bib := resources.Get $source -}} {{- if not $bib -}} {{- errorf "references shortcode in %s: assets/%s does not exist" .Page.File.Path $source -}} {{- else -}}
