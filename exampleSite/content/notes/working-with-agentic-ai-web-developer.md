# 1. Working with Agentic AI: Web Developer

How human skills and agentic skills are dynamically integrated and coordinated across web development responsibilities

## 1.1. Web Developer as an Occupation

{{< preview >}}

A web developer designs, builds, and maintains websites, web applications, and interactive web interfaces. This occupation connects user experience design, backend data management, and network infrastructure by transforming visual prototypes and business requirements into functional, browser-compatible, and secure web experiences. While web designers focus primarily on visual aesthetics and user interfaces, and general software developers may focus on desktop or embedded systems, the web developer specializes in the unique constraints and protocols of the web—such as HTTP, browser rendering engines, responsive design, and web accessibility standards. To ensure these applications perform reliably across diverse devices and network conditions, the developer must understand how frontend frameworks, server-side logic, database architectures, and hosting environments collectively determine the viability and quality of the final web product.

Typical responsibilities of a web developer include:
* web application architecture and technology strategy;
* front-end development and user interface implementation;
* back-end development and server-side logic;
* web performance optimization and scalability;
* web security, testing, and quality assurance; and
* web deployment, hosting, and infrastructure management.

{{< /preview >}}

These responsibilities are fulfilled through distinct tasks and subtasks, each requiring one or more actions with specific skill requirements. Human skills and agentic skills both contribute to these responsibilities, but their levels and forms of involvement differ according to the responsibility, task, action, data, technical environment, and expected outcome.

## 1.2. Human Skills and Agentic Skills in Web Development

Web development increasingly integrates both human skills and agentic skills.

Human skills are reusable capabilities possessed and developed by web developers. They include browser compatibility reasoning, user-centric design translation, web accessibility judgment, architectural planning, security threat modeling, performance intuition, and cross-disciplinary communication.

Agentic skills are reusable capabilities available to AI agents through their underlying models, contextual information, instructions, constraints, tools, and computational resources. In web development, these skills include boilerplate code generation, automated accessibility auditing, cross-browser testing execution, dependency vulnerability scanning, CSS optimization, server log parsing, and API mocking.

Both skill types contribute to the same occupational responsibilities, but their involvement varies by action. Understanding the nuanced accessibility requirements for a complex interactive web dashboard relies primarily on human knowledge of web content accessibility guidelines and keyboard navigation flows; an AI agent may then use agentic skills to scan the codebase for missing ARIA labels and generate the necessary semantic HTML corrections. In back-end development, the developer first determines the appropriate database schema and API contracts, and an AI agent subsequently scaffolds the server-side routes and generates standard database queries. Across these actions, human and agentic skills are activated sequentially or iteratively based on task requirements, with the human professional maintaining oversight and final judgment.

The relationship between these skills is not a fixed division where certain responsibilities permanently belong to humans and others to AI. Instead, human and agentic involvement shifts across tasks and between different actions within the same task.

## 1.3. Dynamic Human–Agentic Skill Integration and Collaboration in Web Development

Web development functions can be understood as an occupation where responsibilities are fulfilled through tasks and subtasks, tasks and subtasks are executed through actions, and actions require appropriate configurations of human and agentic skills.

An occupation provides the overall professional context. For web development, this context encompasses designing web architectures, translating designs into functional interfaces, managing server-side logic, optimizing performance, and deploying secure web applications.

A responsibility represents an expected area of professional work or an outcome that the web developer accomplishes or maintains. Responsibilities such as front-end implementation, back-end logic, and infrastructure management each contain multiple tasks.

A task is a context-dependent unit of work used to fulfill part or all of a responsibility. When a task is too broad or complex for reliable execution, it is decomposed into smaller subtasks.

Tasks and subtasks are executed through one or more actions. Actions represent reusable and configurable operations such as writing a responsive CSS media query, generating a RESTful API endpoint, running a Lighthouse performance audit, configuring an HTTP server, or drafting a continuous integration pipeline script.

Each action has skill requirements. These requirements describe the capabilities needed for effective and reliable execution. Depending on the action and its context, human skills, agentic skills, or an integration of both can satisfy these requirements.

The skills available for web development reside in a skill space containing both human skills and agentic skills. Relevant skills in this space can serve as candidate skills for executing the actions required by a particular task. A human skill in performance intuition, for example, can serve as a candidate for designing an efficient asset-caching strategy, while an agentic skill in bundle size analysis can serve as a candidate for identifying the specific JavaScript libraries causing page load delays.

Candidate skills are evaluated relative to the requirements of the action and its occupational and task context. Appropriate skills are then selected and organized into a skill configuration for execution. Depending on these requirements, a configuration may rely mainly on human skills, mainly on agentic skills, or on an integrated arrangement of both.

### 1.3.1. Skills Competition and Skills Collaboration

Two important relationships can occur between human skills and agentic skills when constructing a skill configuration: skills competition and skills collaboration.

Skills competition occurs when both a human skill and an agentic skill can satisfy the same or similar requirements for an action, but simultaneous application of both is unnecessary. Under a particular occupational and task context, one skill type can provide a better fit for the action than the other.

For example, both a web developer and an AI agent can generate the standard HTML and CSS structure for a static content page based on a provided design file. When the layout rules and design system tokens are clearly specified, the agentic skill provides fast and scalable execution. When the page requires resolving a complex conflict between legacy browser rendering quirks and modern CSS grid behaviors, the developer's human skills provide the necessary compatibility reasoning and workaround design.

The purpose of skills competition is not to establish whether human or agentic skills are generally superior. Rather, it identifies which available skill provides the better fit for a particular action under particular conditions.

Skills collaboration occurs when one skill type alone cannot effectively satisfy the requirements of a task or its actions, or when combining complementary human and agentic skills produces stronger task performance.

Collaboration does not require human and agentic skills to operate simultaneously. Instead, they are activated at different stages of action execution in a sequential, iterative, or recursive manner according to evolving task requirements.

For example, a developer first defines the complex state management logic required for an interactive web form that validates user input against multiple external databases. An AI agent then generates the JavaScript framework components, scaffolds the asynchronous API calls, and drafts the CSS transitions for error states. The developer subsequently reviews the implementation and identifies that the current touch-event handling will fail on specific mobile operating systems. Based on the developer's direction, the agent next refactors the event listeners and generates automated end-to-end tests simulating mobile interactions. Finally, the developer evaluates the resulting interface to ensure it is both functionally robust and accessible. Throughout this sequence, human and agentic skills are activated iteratively as task requirements evolve, while the developer directs the implementation and evaluates its outcomes.

This dynamic relationship allows web developers to leverage the complementary strengths of both skill types rather than relying on a permanent allocation of work.

### 1.3.2. Skill Configuration and Task Execution

A skill configuration specifies which human skills and agentic skills are used to execute the actions associated with a task or subtask and how those skills are coordinated.

The configuration depends on factors such as action requirements, browser compatibility constraints, security criticality, expected traffic volume, available frameworks, information sensitivity, decision consequences, and intermediate results.

For one action, an agentic skill may independently satisfy the requirements. For another, a human skill may provide the better fit. A complex task may require several configurations across multiple actions, with human and agentic skills repeatedly interacting as the task progresses.

The configuration is therefore dynamic rather than permanent. It may change when the action changes, new web standards are published, an agentic result fails to satisfy expected accessibility thresholds, or human interpretation identifies a more efficient rendering approach.

Throughout this process, the web developer remains the professional responsible for directing and controlling the work associated with the occupation and its responsibilities. Agentic AI provides powerful complementary capabilities that expand what the professional can generate, test, analyze, optimize, deploy, and document.

### 1.3.3. Task Performance Evaluation and Skill Space Adaptation

The performance produced through a selected skill configuration is evaluated against predefined evaluation metrics. These metrics determine whether the human skills, agentic skills, or their integrated configuration are sufficiently capable of performing the relevant task and its required actions.

Evaluation criteria depend on the work being performed. In web development, they include code validity, cross-browser compatibility, accessibility compliance, page load speed, security resilience, test coverage, and server stability.

When a selected skill or skill configuration produces performance above the defined threshold, it passes the performance evaluation and is retained for future applications under appropriate conditions. Repeated successful use provides additional evidence about where that skill or configuration performs effectively.

When performance falls below the required threshold, the corresponding skill or configuration is not reused without modification. The relevant human or agentic skills may be refined or reconfigured, existing skills can be combined differently, or new human and agentic skills may be developed or constructed from scratch when the existing skill space lacks adequate capability.

For example, an AI agent first generates CSS layouts that pass standard desktop viewport tests but repeatedly break the visual hierarchy on ultra-wide monitors or specific mobile device orientations. Task performance evaluation identifies this responsive design failure as falling below the required threshold. The agentic skill is then refined through stricter responsive breakpoint constraints, automated multi-viewport testing procedures, or integration with advanced layout simulation tools. The revised skill is evaluated again, and once it satisfies the required performance criteria, it is retained for appropriate future front-end tasks. Human skills follow a corresponding development process: when a developer lacks the knowledge required to implement a newly introduced web authentication protocol, the relevant capability is developed through studying the documentation and experimenting in sandbox environments before its performance is evaluated through subsequent production integrations.

Refined and newly constructed skills that satisfy the required performance criteria are added to the skill space. In this way, task performance evaluation provides feedback not only for completing current work but also for continuously optimizing and expanding the available skill space.

The skill space is not constructed as an isolated collection of occupation-specific representations. Many human and agentic skills used in web development are reusable across occupations. Code generation, database design, API integration, automated testing, security auditing, and technical documentation contribute to work in general software engineering, mobile app development, DevOps, data engineering, and many other fields.

Reusable skills can therefore be represented once and configured differently according to the responsibilities, tasks, actions, and contexts of different occupations. This allows the skill space to serve a growing range of occupations without unnecessarily duplicating or exploding the number of skill representations. Occupational specialization is introduced through task context, action requirements, parameters, data sources, tools, constraints, and skill configurations rather than by creating a completely separate skill representation whenever the same underlying capability appears in another occupation.

The resulting process is adaptive:
occupational responsibility → task and subtask → actions → skill requirements → candidate human and agentic skills → skill configuration → task execution → task performance evaluation → skill refinement, reconfiguration, or construction → optimized and expanded skill space

This cycle allows human and agentic capabilities to evolve alongside the requirements of web development work.

## 1.4. Essential Responsibilities of Web Developer

### 1.4.1. Web Application Architecture and Technology Strategy

Web application architecture and technology strategy establishes the foundational technical blueprint for web projects. This responsibility involves analyzing user and business needs, selecting appropriate programming languages and web frameworks, designing data models, and defining the interaction between client and server environments.

Agentic skills contribute to technology stack comparison, generating initial system interaction diagrams, and drafting technical specification documents. Human skills remain essential for evaluating the long-term maintainability of chosen frameworks, balancing project budgets against performance requirements, and determining how technical constraints align with business objectives.

For example, a team initiates the development of a new data-heavy web portal. The web developer clarifies the expected user concurrency and data retrieval latency constraints. An AI agent then researches compatible web frameworks, generates comparative architecture diagrams, and drafts the initial technical specifications. The developer reviews the proposal and identifies that the suggested framework introduces unacceptable overhead for the required real-time data streaming. The developer revises the architecture to utilize a more lightweight, event-driven approach, and the agent updates the documentation and system models accordingly.

| Human skills|Agentic skills|Integrated collaboration|
| ---|---|---|
| architectural planning, technology selection, requirement analysis, maintainability evaluation|stack comparison, diagram generation, specification drafting, model scaffolding|The AI agent accelerates the research and drafting of technical blueprints, while the developer governs the architectural decisions and ensures the technology stack aligns with long-term project goals.|

### 1.4.2. Front-End Development and User Interface Implementation

Front-end development and user interface implementation translates visual designs and user experience requirements into functional, interactive web pages. This responsibility includes writing structured HTML, CSS, and JavaScript, ensuring cross-browser and cross-device compatibility, implementing responsive design breakpoints, and adhering to web accessibility standards.

Agentic skills are well suited to generating boilerplate UI components, converting design files into initial CSS layouts, running automated accessibility scans, and testing rendering across multiple simulated browser engines. Human skills contribute to interpreting nuanced design intent, resolving complex JavaScript state-management logic, ensuring keyboard navigation flows are intuitive, and making judgment calls on acceptable visual tradeoffs when strict cross-browser parity is technically impossible.

For example, a designer provides a complex, animated prototype for a new web application dashboard. An AI agent parses the design file, generates the foundational HTML structure, and drafts the CSS keyframe animations. The developer reviews the implementation and realizes that the proposed animation sequence triggers excessive layout thrashing on low-end mobile devices, severely degrading battery life and performance. The developer redesigns the animation logic to utilize hardware-accelerated CSS transforms, and the agent updates the code and runs automated frame-rate tests to verify the optimization.

| Human skills|Agentic skills|Integrated collaboration|
| ---|---|---|
| UI/UX translation, accessibility judgment, state-management logic, performance intuition|CSS generation, HTML structuring, accessibility scanning, cross-browser testing|The AI agent scales the translation of designs into code and runs automated compliance checks, while the developer ensures the interface is intuitive, accessible, and performant across diverse hardware.|

### 1.4.3. Back-End Development and Server-Side Logic

Back-end development and server-side logic builds the underlying infrastructure that powers web applications, manages data, and processes user requests. This responsibility includes developing application databases, writing server-side scripts, designing APIs, and integrating the web application with external third-party services.

Agentic skills assist with scaffolding database schemas, generating standard API endpoints, drafting object-relational mapping (ORM) queries, and mocking external API responses for local testing. Human skills are especially important for designing secure authentication flows, formulating complex business logic that governs data transformations, and ensuring database structures scale efficiently with user growth.

For example, an application requires a new module to process user subscriptions and manage tiered access levels. The developer defines the relational data model and the strict security boundaries for payment processing. An AI agent then generates the database migration scripts, scaffolds the RESTful endpoints, and drafts the unit tests for standard CRUD operations. The developer reviews the generated logic and identifies a race condition in the concurrency handling that could allow a user to bypass subscription limits during high-traffic spikes. The developer revises the transaction isolation levels, and the agent updates the code and generates load-testing scripts to verify the fix.

| Human skills|Agentic skills|Integrated collaboration|
| ---|---|---|
| database schema design, security boundary definition, business logic formulation, concurrency reasoning|schema scaffolding, endpoint generation, query drafting, API mocking|The AI agent rapidly builds the foundational server-side code and database structures, while the developer formulates the complex business rules and ensures the architecture is secure and scalable.|

### 1.4.4. Web Performance Optimization and Scalability

Web performance optimization and scalability ensures that web applications load quickly and remain stable under varying levels of user traffic. This responsibility involves analyzing page load metrics, optimizing asset delivery, implementing caching strategies, and refining server-side processes to reduce latency and bandwidth consumption.

Agentic skills retrieve performance audit reports, automate image compression, identify bloated JavaScript bundles, and suggest lazy-loading implementations. Human skills evaluate the user experience impact of aggressive caching, design content delivery network (CDN) strategies, and determine which performance optimizations might inadvertently degrade the perceived quality or interactivity of the site.

For example, an e-commerce web application experiences slow page loads during peak promotional events. An AI agent runs comprehensive performance audits, identifies several unoptimized third-party tracking scripts blocking the main thread, and drafts a lazy-loading configuration to defer their execution. The developer reviews the agent's proposal and recognizes that deferring a specific analytics script will cause the marketing team to lose critical attribution data for the first few seconds of user sessions. The developer designs a custom web worker to offload the script execution without blocking the UI or losing data, and the agent implements the worker logic and updates the performance monitoring dashboards.

| Human skills|Agentic skills|Integrated collaboration|
| ---|---|---|
| performance intuition, caching strategy design, UX impact evaluation, CDN architecture|performance auditing, asset optimization, bundle analysis, lazy-loading scripting|The AI agent automates the discovery of performance bottlenecks and drafts optimization scripts, while the developer balances technical metrics against business needs and user experience quality.|

### 1.4.5. Web Security, Testing, and Quality Assurance

Web security, testing, and quality assurance protects web applications from vulnerabilities and ensures they function correctly across diverse environments. This responsibility includes implementing web security measures, writing automated test suites, performing cross-browser testing, and maintaining ongoing site revisions.

Agentic skills contribute to continuous dependency vulnerability scanning, executing end-to-end browser automation tests, identifying insecure HTTP headers, and generating test cases for standard user flows. Human skills define the application's threat model, interpret ambiguous security warnings, design test scenarios for complex edge cases, and authorize the deployment of critical security patches.

For example, a routine automated scan flags a potential cross-site scripting (XSS) vulnerability in a user-generated content forum. An AI agent isolates the specific input field, generates a proof-of-concept exploit, and drafts a patch utilizing standard output-encoding libraries. The developer reviews the patch and realizes that applying a blanket encoding rule will strip necessary formatting tags required by the site's rich-text editor. The developer designs a custom sanitization pipeline that allows specific safe HTML tags while neutralizing script injections, and the agent updates the test suite to verify that both the security boundary and the rich-text functionality remain intact.

| Human skills|Agentic skills|Integrated collaboration|
| ---|---|---|
| threat modeling, security boundary definition, edge-case test design, patch authorization|vulnerability scanning, E2E test execution, header analysis, test case generation|The AI agent continuously monitors for standard vulnerabilities and automates regression testing, while the developer designs nuanced security protocols and authorizes critical deployments.|

### 1.4.6. Web Deployment, Hosting, and Infrastructure Management

Web deployment, hosting, and infrastructure management governs the environment where the web application lives and how it is delivered to users. This responsibility includes configuring HTTP servers, managing domain name registrations, setting up continuous integration and continuous deployment (CI/CD) pipelines, establishing backup procedures, and monitoring server health.

Agentic skills assist with drafting infrastructure-as-code templates, automating backup schedules, parsing server error logs to detect downtime, and generating CI/CD pipeline scripts. Human skills evaluate the reliability and compliance of hosting providers, design disaster recovery protocols, manage the financial and operational aspects of domain and server renewals, and control the final authorization for production deployments.

For example, the organization decides to migrate its primary web application to a new cloud hosting environment to improve global latency. An AI agent generates the infrastructure provisioning scripts, configures the load balancers, and drafts the automated database migration pipeline. The developer reviews the infrastructure setup and identifies that the proposed auto-scaling rules lack a necessary cooldown period, which could result in runaway server costs during a minor traffic anomaly. The developer revises the scaling parameters and defines the disaster recovery failover sequence, and the agent updates the deployment scripts and configures the automated monitoring alerts.

| Human skills|Agentic skills|Integrated collaboration|
| ---|---|---|
| infrastructure governance, disaster recovery planning, hosting evaluation, deployment authorization|infrastructure scripting, backup automation, log parsing, CI/CD pipeline generation|The AI agent automates the provisioning and monitoring of server environments, while the developer governs the infrastructure strategy, manages risk, and authorizes production releases.|

## 1.5. Changing Human and Agentic Involvement Across Web Developer Responsibilities

Human skills and agentic skills are involved throughout web development, but their relative involvement differs across responsibilities and changes during task execution.

| Responsibility|Typical human involvement|Typical agentic involvement|Typical integration|
| ---|---|---|---|
| Web application architecture and technology strategy|Very high|High|Agentic stack comparison and specification drafting combined with human architectural planning and maintainability evaluation.|
| Front-end development and user interface implementation|Very high|Very high|Agentic CSS generation and accessibility scanning governed by human UI/UX translation and performance intuition.|
| Back-end development and server-side logic|Very high|High|Agentic schema scaffolding and endpoint generation supporting human business logic formulation and security boundary definition.|
| Web performance optimization and scalability|High|Very high|Agentic performance auditing and asset optimization combined with human caching strategy design and UX impact evaluation.|
| Web security, testing, and quality assurance|Very high|Very high|Agentic vulnerability scanning and test execution governed by human threat modeling and patch authorization.|
| Web deployment, hosting, and infrastructure management|High|Very high|Agentic infrastructure scripting and log parsing combined with human disaster recovery planning and deployment authorization.|

These involvement levels are not permanent allocations. A single responsibility may contain actions where human and agentic skills compete as alternative capabilities and other actions where they collaborate sequentially, iteratively, or recursively.

The practical objective is to construct skill configurations that use the most suitable available capabilities for each part of the work and revise those configurations when task performance evaluation shows that another arrangement performs more effectively or reliably.

## 1.6. Working as a Web Developer with Agentic AI

Agentic AI is becoming an increasingly powerful component of web development. Web developers should therefore adopt and integrate AI agents as complementary participants in professional workflows rather than treating them only as occasional tools for generating boilerplate code, formatting CSS, or drafting deployment scripts.

This shift does not reduce the importance of web standards, architectural reasoning, and user-centric design expertise. Human professionals remain responsible for the occupation and its corresponding responsibilities. They understand browser constraints, define meaningful user interactions, interpret accessibility requirements, determine appropriate performance tradeoffs, evaluate security vulnerabilities, communicate with design and backend teams, control consequential production deployments, evaluate task performance, and decide how human and agentic skills are configured and improved.

At the same time, agentic skills greatly expand the volume and complexity of development work that can be executed. AI agents ingest massive design files, generate and test responsive layouts, scan thousands of dependencies for security flaws, automate cross-browser compatibility tests, optimize server configurations, and synthesize extensive technical documentation at a scale difficult to achieve through direct human effort alone.

Strong web development practice is therefore not based on maximizing human work or agentic work independently. It is based on finding appropriate configurations of human skills and agentic skills for the responsibilities, tasks, subtasks, and actions being performed.

Where a human skill and an agentic skill can independently perform the same action, skills competition identifies which is better suited to the current context. Where work requires complementary capabilities, skills collaboration results in human and agentic skills being activated sequentially, iteratively, or recursively to achieve stronger task performance than either skill type achieves alone.

Task performance evaluation then determines whether selected skills and configurations satisfy predefined expectations. Successful skills are retained and reused, while inadequate skills are refined, reconfigured, or newly developed. The resulting capabilities return to an increasingly useful skill space that supports web development and, where capabilities are reusable, other occupations as well.

For a web developer, working effectively with agentic AI means treating AI as a powerful complementary capability integrated into everyday professional routines while maintaining human control of occupational responsibilities. Through appropriate skill selection, competition, collaboration, evaluation, and continuous improvement, human professionals and agentic AI work together to achieve web applications that are more efficient, scalable, accessible, secure, adaptable, and fundamentally aligned with user needs.
