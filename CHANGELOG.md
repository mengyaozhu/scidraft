# Changelog

All notable changes to SciDraft are documented in this file.

## Initial Release

### Added
- Introduced SciDraft, a Hugo theme designed for scientific writing, research notes, and academic publishing.
- Added support for mathematical notation using KaTeX.
- Added BibTeX-based citations for academic references.
- Added Mermaid diagram support.
- Added research-note organization and entry indexes.
- Added an example site demonstrating theme configuration and supported features.
